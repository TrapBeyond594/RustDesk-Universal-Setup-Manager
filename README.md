# 🛠️ Универсальный менеджер RustDesk Server

Кароче, этот скрипт представляет собой удобный инструмент для управления RustDesk Server на вашем Linux-сервере. Скрипт поддерживает как **бесплатную**, так и **Pro** версии, работает на большинстве популярных дистрибутивов и предоставляет графический интерфейс прямо в терминале.

---

## 🌟 Основные возможности

- **🚀 Быстрая установка**: Автоматическая установка бесплатной или Pro версии RustDesk.
- **🔄 Обновление в один клик**: Проверка последних версий на GitHub и обновление системы.
- **🧹 Полное удаление (с корнями)**: Безопасное и тщательное удаление всех следов сервера, логов и конфигураций.
- **🛡️ Управление безопасностью**: Просмотр публичных ключей для подключения клиентов.
- **🌐 Веб-панель (Pro)**: Быстрый доступ к информации о панели управления Pro-версии.
- **🐧 Универсальность**: Поддержка Debian, Ubuntu, CentOS, RHEL, Fedora и Arch Linux.

---

## 🚀 Быстрый запуск

Скопируйте и вставьте следующую команду в терминал вашего сервера:

```bash
mkdir -p rustdesk-mgr && cd rustdesk-mgr && wget https://raw.githubusercontent.com/TrapBeyond594/RustDesk-Universal-Setup-Manager/rustdesk-universal-setup/rustdesk-manager.sh https://raw.githubusercontent.com/TrapBeyond594/RustDesk-Universal-Setup-Manager/rustdesk-universal-setup/rustdesk-utils.sh && chmod +x rustdesk-manager.sh rustdesk-utils.sh && sudo ./rustdesk-manager.sh
```

---

## 📋 Использование

После запуска скрипта вы увидите интерактивное меню:

1.  **Установка Free/Pro**: Выберите желаемую версию, и скрипт сделает всё за вас.
2.  **Обслуживание**: Скрипт обновит репозитории системы и проверит наличие новых версий RustDesk Server на GitHub.
3.  **Статус**: Мгновенная проверка работы всех компонентов (Signal и Relay серверы).
4.  **Удаление**: Если вам нужно очистить сервер, функция "удаления с корнями" удалит все файлы, службы и логи.

---

## ⚙️ Настройка клиентов

Для подключения клиентов к вашему серверу:
1. Откройте RustDesk на компьютере.
2. Перейдите в **Настройки -> Сеть**.
3. Введите IP вашего сервера в поля **ID Server** и **Relay Server**.
4. В поле **Key** вставьте публичный ключ, полученный через скрипт (опция 6).
